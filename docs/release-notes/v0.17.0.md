# Molaplan v0.17.0 – aurinkosähkö ja sähköauton laturit

**Tärkeää: uusia ominaisuuksia ei ole vielä kokeiltu oikealla laitteella (testaamatta laitteella).** Kaikki on testattu dokumentaation mukaan rakennettuja simuloituja laitteita ja palvelimia vasten. Kerro, mikä toimii.

## Aurinkosähkö (R288, R305–R309)
Lisää laite → **Aurinkosähkö** → valitse invertteri. Ruudut: tuotanto nyt (W), tuotto tänään ja yhteensä (kWh), verkosta osto/myynti (W, + osto / − myynti), osto- ja myyntilukemat, akun varaus (%) ja teho, kodin kulutus.

| Merkki | Yhteys | Testattu |
|---|---|---|
| Huawei SUN2000 (+ LUNA2000-akku) | Paikallinen: Modbus TCP SDonglen kautta | Simuloitu laite |
| Huawei FusionSolar | Pilvi, valinnainen | Simuloitu palvelin |
| Fronius (Symo, Primo, Gen24, Tauro) | Paikallinen: Solar API | Simuloitu laite |
| SolarEdge | Paikallinen: Modbus TCP (portti 1502) | Simuloitu laite |
| SolarEdge monitoring | Pilvi, valinnainen | Simuloitu palvelin |
| SMA (Sunny Boy, Tripower, Storage) | Paikallinen: Modbus TCP | Simuloitu laite |
| SMA Energy Meter / Home Manager | Paikallinen: Speedwire, ei kirjautumista | Simuloidut lähetykset |
| Growatt | Paikallinen: Modbus (RS485→TCP-muunnin tai ShineLan-X) – tarkista lukemat | Simuloitu laite |
| Growatt OpenAPI | Pilvi, valinnainen | Simuloitu palvelin |
| Muu SunSpec-invertteri (Kostal, ABB…) | Paikallinen: Modbus TCP | Simuloitu laite |

- SMA Sunny Portal ei ole vielä mukana: se vaatii SMA:n kehittäjärekisteröinnin. Paikallinen Modbus tai Energy Meter on nopeampi.
- Invertteriä vain luetaan, sitä ei ohjata.

## Sähköauton laturit (R289, R310–R313)
Lisää laite → **Sähköauton laturi**. Ruudut: tila, lataus päälle/pois, latausteho, tämän latauksen energia ja virtaraja (A).

| Merkki | Yhteys | Testattu |
|---|---|---|
| Mikä tahansa OCPP 1.6J -laturi (Wallbox, Alfen, ABB, go-e, Etrel…) | Paikallinen: laturi ottaa yhteyden Molaplaniin tai kotisiltaan (ws://<IP>:9000/ocpp/) | Simuloitu laturi |
| Easee | Pilvi | Simuloitu palvelin |
| Zaptec | Pilvi | Simuloitu palvelin |
| Wallbox | Pilvi (paikallisesti OCPP:llä) | Simuloitu palvelin |

## Automaatiot (R314)
- **Lataa auto aurinkosähkön ylijäämällä**: laturi päälle, kun verkkoon myydään yli 1,4 kW, ja pois, kun verkosta ostetaan yli 1 kW.
- **Lataa auto halvimpina tunteina**: laturi päälle päivän halvimpina tunteina ja pois, kun ne loppuvat.
- Uusi ehto "Halvimmat tunnit". Pitkään odottava automaatio ei enää pysäytä muita automaatioita.
