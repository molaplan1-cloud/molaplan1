# Molaplan v0.20.16 – kameran live-video ja still-kuva RTSP:stä

**Android-käyttäjät: lataa tämän julkaisun `molaplan-android-arm64.apk`, älä universal-versiota.** Asenna vanhan päälle (**Päivitä**) – älä poista sovellusta äläkä tyhjennä tietoja, niin asetukset säilyvät.

*Uudet kohdat (t331ua0): testaamatta laitteella. Testattu mallikameralla oikeilla paikallisilla yhteyksillä; oikea Sonoff-kamera tutkittiin vain lukemalla (ilman kirjautumista).*

### Kamerakuva ei näkynyt (R600–R602)
- **Syy 1:** sovellus piilotti RTSP-videon, jos se luuli olevansa "poissa kotoa" (kotisillan verkkotiedon perusteella), vaikka tämä laite olisi tavoittanut kameran. Nyt video yritetään aina ensin tästä laitteesta; vain jos kamera ei vastaa täältä, kuva tulee kotisillan kautta.
- **Syy 2:** Sonoff-kamera vastaa RTSP-pyyntöön ilman kirjautumista "454" eikä koskaan kysy salasanaa, joten videosoitin (ffmpeg/libmpv) ei lähettänyt tunnusta lainkaan. Nyt sovellus tarkistaa kameran ensin ja tarvittaessa lähettää tunnuksen heti paikallisen välityksen kautta.
- Virheteksti kertoo oikean syyn (kamera ei vastaa / tunnus hylätty / osoite väärä / kuvaa ei saatu toistettua), ja siinä on **Yritä uudelleen** sekä **Tekniset tiedot** (ei salasanoja). Harhaanjohtava "näkyy vain kotiverkossa" -teksti poistui.

### Still-kuva RTSP-videosta (R603–R604)
- Jos kameralla ei ole still-kuvan osoitetta (ONVIF GetSnapshotUri puuttuu), sovellus tekee still-kuvia videovirrasta: laitteella sovelluksen omalla soittimella, kotisillalla soittimella tai `ffmpegillä`. Poissa kotoa ja selaimessa ruutu näyttää nämä kuvat kotisillan kautta (kotisillan tietokoneella tarvitaan ffmpeg tai Molaplan-sovellus kotisiltana; ESP32-silta ei osaa purkaa videota).

Vaatimukset: `docs/REQUIREMENTS.md` R600–R605.
