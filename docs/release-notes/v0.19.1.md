# Molaplan v0.19.1 – korjausjulkaisu: Android-sovellus ei käynnistynyt

**Android-versiot 0.18.0, 0.18.1 ja 0.19.0 kaatuivat heti käynnistyksessä** (Samsung: "Molaplan pysähtyy jatkuvasti" / ehdotus tyhjentää välimuisti). Syy oli Android-julkaisukäännöksen koodin karsinta (R8): se poisti WorkManager-kirjaston tietokantaluokasta konstruktorin, jota Android tarvitsee sovelluksen käynnistyessä. Tämä tuli tablettiwidgettien myötä versiossa 0.18.0. Virhe kaatoi sovelluksen ennen kuin mikään Molaplanin oma koodi ehti käynnistyä, myös kotisillan ja ilmoitusten kuuntelijan taustalla.

### Korjaus (R400)
- Julkaisukäännöksen karsintasäännöt säilyttävät WorkManagerin, Roomin ja Molaplanin omat Android-luokat.
- Automaattinen tarkistus: jokainen julkaisun APK tarkistetaan, ettei käynnistyksessä tarvittavia luokkia ole karsittu.
- Testattu Android-emulaattorissa: 0.19.0 kaatui samalla virheellä, 0.19.1 käynnistyy, ja päivitys vanhan version päälle säilyttää asetukset.

### Näin korjaat laitteen
Sovelluksen oma päivitys ei voi toimia, koska sovellus ei käynnisty. Asenna uusi versio käsin vanhan päälle – **älä poista sovellusta äläkä valitse "Tyhjennä tiedot"**, niin asetukset ja tiedot säilyvät (välimuistin tyhjentäminen on harmitonta):
1. Lataa tämän julkaisun **molaplan-android-arm64.apk** (64-bittiset laitteet, käytännössä kaikki; sovelluksen oma päivitys on asentanut juuri tämän). Universal-APK ei asennu arm64-version päälle (pienempi versiokoodi).
2. Avaa tiedosto laitteella ja valitse **Päivitä**, tai USB:n kautta: `adb install -r molaplan-android-arm64.apk`.
3. Avaa Molaplan.

Muuten sisältö on sama kuin v0.19.0:ssa.
