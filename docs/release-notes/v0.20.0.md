# Molaplan v0.20.0 – Zigbee2MQTT, Z-Wave JS, Nanoleaf, WLED, Phoscon ja Nuki

**Tärkeää: uusia ominaisuuksia ei ole vielä kokeiltu oikealla laitteella (testaamatta laitteella).** Kaikki on testattu valmistajien julkisen dokumentaation mukaan rakennettuja simuloituja laitteita vasten. Kerro, mikä toimii.

Tämä versio lisää tuen smarterhome.sk-kaupan merkeille. Koko merkkilista ja tilanne: docs/BRANDS-SMARTERHOME.md.

## Uudet laitetyypit (Lisää laite)

| Laite | Yhteys | Paritus | Ruudut |
|---|---|---|---|
| **Zigbee2MQTT** – Aqara, frient, Heiman, GLEDOPTO, MOES, NOUS, Danfoss Ally, Salus, EUROtronic, POPP, IKEA, Philips Hue… | MQTT-välittäjä kotiverkossa (Zigbee2MQTT + mikä tahansa Zigbee-tikku, esim. SMLIGHT SLZB, SONOFF, ConBee) | Välittäjän käyttäjätunnus ja salasana | valot ja kytkimet (kirkkaus), lukot (vahvistus), verhot, termostaatit (lämpötila + asetusarvo), ovi-, liike-, vuoto- ja savuanturit, mittaukset |
| **Z-Wave JS** – Aeotec, FIBARO, Nice, Heatit, HELTUN, MCO Home, Philio, POPP, Remotec, Sensative, tedee GO2, Z-Wave.Me… | Z-Wave JS UI / Z-Wave JS -palvelin (portti 3000) | Ei tarvita | kytkimet, himmentimet, anturit, energiamittarit, hälytykset, termostaatin asetusarvo, ovilukot (vahvistus) |
| **Nanoleaf** | Paikallinen OpenAPI | Pidä virtapainiketta 5–7 s | virta, kirkkaus, tehosteet |
| **WLED** (GLEDOPTO, SMLIGHT SLWF-11, Athom…) | Paikallinen JSON-API | Ei tarvita | virta, kirkkaus, esiasetukset |
| **Phoscon / deCONZ** (ConBee, RaspBee) | Paikallinen REST-API | Phoscon → "Todenna sovellus" | valot, anturit, huoneet, tilanteet |
| **Nuki Bridge** (älylukot, Opener) | Paikallinen HTTP-API (portti 8080) | Paina Bridgen painiketta | lukitse/avaa (vahvistus), salpa auki, Opener, akku |

## Tulossa
Matter (Eve, Meross, tado X, Nuki/Aqara Matter-mallit), DoorBird, tedee Bridge, FIBARO Home Center 3 / Nice Yubii, HMS Intesis, Homey, Z-Way, tado, Netatmo. Niitä voi jo nyt käyttää valinnaisen Home Assistant -sillan kautta – haku galleriassa löytää merkin ja kertoo vaihtoehdon.
