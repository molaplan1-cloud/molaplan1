# Molaplan v0.20.36 – Päivitys tarjoaa vain valmiin version

**Android-käyttäjät: lataa tämän julkaisun `molaplan-android-arm64.apk`, älä universal-versiota.** Asenna vanhan päälle (**Päivitä**) – älä poista sovellusta äläkä tyhjennä tietoja, niin asetukset säilyvät.

*Uudet kohdat (t353ua0): testaamatta laitteella. Testattu yksikkö- ja käyttöliittymätesteissä.*

### Päivitystarkistus ei enää jää rakentuvan version taakse (R735–R739)
- Sovellus tarjoaa vain uusimman version, jonka asennustiedosto (Windows-zip tai Android-APK) ja SHA256SUMS ovat jo julkaistu. Pelkkä uudempi git-tunniste tai kesken oleva julkaisu ei aiheuta virhettä "Päivitys ei ole vielä ladattavissa".
- Tarkistus lukee ensin molaplan.com/version.json-tiedostoa, mutta vain jos sen version tiedostot ovat saatavilla. Muuten tarjotaan uusin valmis GitHub-julkaisu.
- Jos uudempaa ladattavaa versiota ei ole, näet ilmoituksen **Sovellus on ajan tasalla.** Jos uudempi versio on vasta valmistumassa, lisätään lyhyt huomautus: **Uudempi versio valmistuu pian.**
- molaplan.com-sivuston version.json päivitetään vasta, kun Windows-asennustiedosto on GitHubissa, jotta aiemmat versiot (kuten 0.20.29) voivat päivittää itsensä ilman virhettä.

Vaatimukset: `docs/REQUIREMENTS.md` R735–R739.
